# Cedar Weekly Sync 2026-08-14

## Import

The team agreed that importing an existing folder must not reorganise it. Cedar
reads what is there and writes only where the user pointed it.

## Stale index

A stale index is labelled stale in the interface. The previous answers stay
available while a rebuild runs, and a rebuild that fails says so.

## Pilot group

Three reviewers per team for the pilot. A larger group waits for the handover
report.
