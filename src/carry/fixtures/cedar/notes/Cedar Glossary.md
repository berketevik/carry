# Cedar Glossary

**Record** - one addressable note with an identity that survives renaming.

**Revision** - a monotonic counter per record; corrections increment it.

**Source** - a configured folder with an identifier, a scope label and a
read or write capability. A scope label describes attribution, not permission.

**Derived index** - disposable retrieval state rebuilt from the sources.

**Receipt** - the evidence that something was actually persisted, as opposed to
merely configured.
