# Cedar synthetic corpus

Every name, date and decision here is invented for testing Carry. Cedar is not a
real product, team or customer, and the folder contains no personal data. The
corpus is frozen: acceptance runs assume these files byte for byte.

Deliberate properties the acceptance scenarios rely on:

- `Cedar Pilot Plan.md` states the pilot delivery date once: October 15, 2026.
- `Maple Handover.md` is a decoy project with a different date, so a query about
  Cedar must not answer with Maple's date.
- No file mentions a budget or any monetary amount. A budget question has to end
  in an explicit no-evidence answer.
